# 学姐通信 · XUEJIE MOBILE

真实 AI Agent 工作台：用户交给 AI 团队任务，后台执行，像素办公室显示真实工作状态。不是游戏。

项目位于 [xuejie-mobile-pixel-agent-office](xuejie-mobile-pixel-agent-office/README.md)。当前 `web-access` 分支提供电脑和手机的浏览器入口、私人工作室登录及 Render 持久化部署配置；办公室和六只宠物保持原样。

[打开部署设置](https://render.com/deploy?repo=https://github.com/NANXI97/CODEX/tree/web-access)

这会打开 Render 的部署表单，**不是已上线的工作室网址**。需要自己的 Render 账号，在表单中安全填写 `APP_PASSWORD` 和 `LLM_API_KEY`。托管有费用；步骤、费用与数据保存说明见 [浏览器部署说明](xuejie-mobile-pixel-agent-office/DEPLOYMENT.md)。不要在聊天或 Git 中发送密码和 Key。
